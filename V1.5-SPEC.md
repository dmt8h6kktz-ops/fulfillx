# FulFillX — V1.5 Specification: Toolbox Polish

Builds on V1.4 (the Toolbox, already built). These are TARGETED refinements to tools that
already exist — do NOT rebuild the Toolbox, the diary engine, or any tool from scratch, and
do not touch V1.1–V1.3 features (journals, habits, history, photos, week strip). Reuse all
existing systems: the Slate/Graphite themes, the guided-diary engine and per-tool history,
the V1.3 reminder pattern, and the Phosphor icons.

## HOW TO BUILD THIS
Apply the five changes below one at a time, with targeted/incremental edits. After each:
confirm it works, summarize, and commit ("V1.5 polish: <name>"). Never break or discard
existing localStorage / IndexedDB data. Verify both Slate and Graphite. Single self-contained
FulFillX.html.

---

## 1. One-step-per-screen flow (Flow Principle)
Convert the guided diary engine so each tool shows ONE step per screen with Back / Next —
Next advances, Back preserves what was typed — ending in a final editable REVIEW screen that
assembles the whole entry before saving. Apply to all diary tools. Keep the quick in-the-
moment tools snappy (5-4-3-2-1 Grounding, Nervous-System Reset): minimal taps, no long wizard.

Leave unchanged (the method name already states the purpose): Shame Resilience,

## 3. The 5 R's — craving label + frequency history
Add a Step 0 "What's the craving?" before Relabel: a short text label, with previously-used
labels shown as tappable chips (so "smoke" stays "smoke") plus the option to type a new one.
Tag the saved entry with that label. In this tool's History, show a frequency view grouped
and counted by craving label, most-craved first (e.g. "Smoke ×30 · Beer ×15 · Sugar ×10");
tapping a label lists those dated entries. Keep it neutral and non-judgmental. The five steps
(Relabel, Reattribute, Refocus, Revalue, Recreate) and the "every refusal is a win" review
note are unchanged.

## 4. Mind Dump — recategorize, rebuild flow, weekly schedule
- Move Mind Dump from the in-the-moment group into the Reflect & journal group, and stop
  logging it to `fulfillx.toolUsage` — it now saves full dated entries.
- Rebuild its flow as three pages:
  (a) DUMP — pick a duration, then start; the timer is HIDDEN once started (no visible
      countdown); a NUMBERED list field where pressing Enter starts the next numbered line;
      a Done button when time's up.
  (b) CROSS OUT — show every numbered item; tap to strike out the ones that don't matter.
  (c) ACTION PLAN — list the remaining (un-crossed) items one per line; under each, a field
      to write what you need to do to accomplish it.
  Save a dated entry (remaining items + their action steps) to history.
- Make Mind Dump schedulable with an optional weekly reminder (reuse the existing V1.3
  reminder pattern; reliable native firing comes with the Capacitor wrapper later).

## 5. Elephant & Rider — trigger ending + icon
- Flow, one step per screen:
  1) "What happened — the moment the elephant turned?"
  2) "What did the elephant want or feel right then?"
  3) "Where was the rider? What would it have chosen?"
  4) "What helped, or could help, you create space and wait out the pull?"
  5) closing — "What set it off? Name the specific trigger (a scent, tone, word, place,
     time)", with past triggers offered as tappable chips.
  Review screen — assemble + edit + save, tagged with the trigger.
- HISTORY: surface recurring triggers over time so the pattern becomes visible.
- ICON: change this tool's icon from ph-paw-print to ph-lightning (reads as a reactive
  spark, fitting "Reactivity"). If it looks odd at small size, ph-horse or ph-steering-wheel
  are acceptable fallbacks — report which you used.
