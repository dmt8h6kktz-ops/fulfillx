# FulFillX — V1.4 Specification: The Toolbox (Phased Build)

Builds on V1.3. Same rules: single self-contained `FulFillX.html` (HTML + CSS + JS inline,
no build step, no deps except Google Fonts), runs by double-clicking. Reuse the existing
Slate/Graphite themes, Baloo 2 / Fredoka type, widget engine, habit scheduler, history, and
IndexedDB photo store — do NOT restyle or rebuild them.

## HOW TO BUILD THIS (read first)
Execute the seven phases below **in order, one at a time**, with targeted/incremental edits.
Do NOT rewrite the whole file in one response. After each phase: confirm its acceptance
criteria, summarize what changed and how to verify it, commit ("V1.4 Phase N: <name>"), then
continue. Never break or discard existing localStorage / IndexedDB data. If a phase can't be
completed cleanly, stop and explain.

## GOAL OF V1.4
Turn the Toolbox tab into a real library of credited, faithfully-implemented self-development
tools from real professionals. Each tool shows its true source, explains itself with an "i"
info popup (use case + example), runs a guided flow, and — where it's a reflective tool —
saves dated entries to its own history so the user can look back and see patterns over time.

## NON-NEGOTIABLE ATTRIBUTION & COPYRIGHT RULES
- Display each tool's credit line EXACTLY as written in the Tool Catalog below.
- All step text is OUR paraphrase of the method — never reproduce passages from the books.
- Never invent or alter an attribution. 5-4-3-2-1 has NO individual author — label it "a
  widely used grounding technique."
- Urge/craving content (the 5 R's) stays neutral and non-judgmental; it must work for any
  compulsion the user is privately working on, naming no specific behavior by default.

## DATA MODEL

### Tool registry (in code, not user-editable)
A JS array of tool objects, each: `id, name, icon, purpose, credit, infoUse, infoExample,
type, config`. Types: `diary`, `braindump`, `grounding`, `statepractice`, `ladder`,
`bullseye`, `attachment`. `config` holds type-specific data (e.g. diary `steps`).

### Entries & state (localStorage)
- `fulfillx.toolEntries` = `{ [toolId]: [ { date:"YYYY-MM-DD", ts, data:{...} } ] }` — dated
  entries for reflective tools (diary, ladder, bullseye, attachment reflection). Keyed by
  tool so each has its own history.
- `fulfillx.attachmentStyle` = "secure" | "anxious" | "avoidant" | null (set once, editable).
- `fulfillx.values` = `{ work:[], leisure:[], relationships:[], growth:[] }` — the living
  values list (editable); Bull's Eye snapshots go in toolEntries["values"].
- `fulfillx.toolUsage` = `{ [toolId]: ["YYYY-MM-DD", ...] }` — optional "used today" log for
  in-the-moment tools (Mind Dump, 5-4-3-2-1, Nervous-System Reset).

### Per-tool history
Reflective tools expose a History view (most-recent-first list of dated entries; tap to
reopen read-only). In-the-moment tools optionally record a usage date. Reuse V1.3 history
patterns/visual style.

## TOOL CATALOG (content reference for all phases)
Credit lines are to be shown verbatim. Steps are our paraphrase; render each as a labeled
text field unless marked as a choice.

### Reflective / diary tools (type: diary)
**The 5 R's** · icon 🔁 · purpose "Work through a craving or urge, step by step."
- credit: "Four Steps by Dr. Jeffrey Schwartz (Brain Lock); adapted for cravings and expanded with a fifth step by Dr. Gabor Maté (In the Realm of Hungry Ghosts)."
- infoUse: "When an urge or craving shows up — for anything — and you want to meet it with awareness instead of autopilot."
- infoExample: "An urge to reach for your phone hits. You relabel it as a false signal, trace it to an old habit loop, refocus elsewhere, weigh what giving in really costs, and reconnect to the life you'd rather build."
- steps: 1) Relabel — "Name the urge for what it is (an urge, not a command)." 2) Reattribute — "Where's this really coming from? An old signal/habit loop, not the true you." 3) Refocus — "What will you do instead, right now, to let it pass? Any redirection counts." 4) Revalue — "Play it forward: what does giving in actually cost you?" 5) Recreate — "Reconnect to your values: what life or person are you choosing instead?"
- footer note: "Urges recur — every time you turn one away is a win."

**Elephant & Rider** · icon 🐘 · purpose "Catch the moment emotion takes the reins."
- credit: "From Jonathan Haidt, The Happiness Hypothesis (2006)."
- infoUse: "When you reacted automatically and want to understand the pull behind it."
- infoExample: "You snapped before you 'decided' to — the elephant (emotion) turned before the rider (reason) had a say. Journaling these moments builds the awareness to catch them earlier."
- steps: 1) "What happened — the moment the elephant turned?" 2) "What did the elephant want or feel right then?" 3) "Where was the rider? What would it have chosen?" 4) "What might help you notice this turn earlier next time?"

**Shadow Work** · icon 🌓 · purpose "Get curious about what you reject in yourself."
- credit: "Concept by Carl Jung; practical exercise from Robert A. Johnson, Owning Your Own Shadow."
- infoUse: "When someone triggers a judgment or reaction far bigger than the moment deserves."
- infoExample: "A coworker's bragging irritates you intensely. Shadow work asks what that reaction protects or hides in you — often a disowned part worth integrating rather than exiling."
- steps: 1) "What triggered a strong reaction or judgment?" 2) "What exactly did you react to in them?" 3) "Where might that same trait live, unowned, in you?" 4) "What would it look like to accept or integrate that part?"

**Dichotomy of Control** · icon ⚖️ · purpose "Separate what's yours to control from what isn't."
- credit: "From Epictetus, the Enchiridion (Stoic philosophy)."
- infoUse: "When you're spinning on something stressful and want to spend energy where it counts."
- infoExample: "A flight's delayed and you're fuming. The delay isn't yours to control; your response and next move are. You invest there and practice letting the rest go."
- steps: 1) "What's troubling you right now?" 2) "What part is NOT up to you (outcomes, others, externals)? Name it to set it down." 3) "What part IS up to you (your judgments, choices, actions)?" 4) "One thing in your control you'll put energy into?"

**Shame Resilience** · icon 🫂 · purpose "Loosen shame's grip when it hits."
- credit: "From Brené Brown's Shame Resilience Theory (I Thought It Was Just Me)."
- infoUse: "When you feel small, exposed, or 'not enough' and want to come back to yourself."
- infoExample: "After a mistake the 'I'm a fraud' feeling floods in. You name the shame and its trigger, reality-check the story, reach out to someone safe, and say it out loud — where shame loses its power."
- steps: 1) Recognize — "Name the shame and its trigger. Where do you feel it in your body?" 2) Critical awareness — "Whose expectation is driving this? Is it realistic or fair?" 3) Reach out — "Who is someone safe you could share this with?" 4) Speak shame — "Say it plainly: what's the story you're afraid is true?"

**Thought Record (CBT)** · icon 🧩 · purpose "Test a painful thought against the evidence."
- credit: "Cognitive Behavioral Therapy — Dr. Aaron Beck; popularized by Dr. David Burns (Feeling Good)."
- infoUse: "When an upsetting thought feels like fact and you want to check it."
- infoExample: "'Everyone thought my talk was terrible.' You log the situation, the thought, the feeling, spot the trap (mind-reading, all-or-nothing), and write a fairer view — and the feeling eases."
- steps: 1) "Situation — what happened?" 2) "Automatic thought — what went through your mind?" 3) "Feeling — what did you feel, and how strong (0–100%)?" 4) "Thinking trap? (all-or-nothing, mind-reading, catastrophizing…)" 5) "Balanced view — a fairer, more accurate thought?" 6) "Re-rate the feeling now."
- note: distinct from Observer — this CHALLENGES the thought's accuracy.

**Nonviolent Communication (NVC)** · icon 💬 · purpose "Say something hard without blame."
- credit: "Nonviolent Communication — Dr. Marshall Rosenberg."
- infoUse: "When you need to raise something difficult and want to be heard, not met with defensiveness."
- infoExample: "Instead of 'you never listen': observation ('the last few talks you were on your phone'), feeling ('I felt unimportant'), need ('I need to feel heard'), request ('could we talk 10 minutes phone-down?')."
- steps: 1) Observation — "Just the facts, no judgment: what happened?" 2) Feeling — "What do you feel about it?" 3) Need — "What underlying need is behind that feeling?" 4) Request — "A clear, doable ask — what would help?"
- output: assemble the four answers into a draft message the user can copy/keep.

### In-the-moment tools
**Mind Dump** (type: braindump) · icon 🧠 · purpose "Clear a cluttered mind onto the page."
- credit: "Mind dump technique described by Mo Gawdat."
- infoUse: "When your head is noisy and overwhelmed and you can't think straight."
- infoExample: "Before bed your mind is spinning. You dump it all out for a few minutes, cross off what doesn't matter, and turn the rest into a short action list — and your head is quieter."
- flow: pick a duration (e.g., 2/5/10 min) → timed free-write textarea → review and cross off items that don't matter → capture what remains as next actions → save dated entry (the actions).
- build note: confirm exact wording/framing from the Gawdat–Sinek episode before finalizing.

**5-4-3-2-1 Grounding** (type: grounding) · icon 🌿 · purpose "Anchor yourself in the present."
- credit: "A widely used grounding technique." (NO individual attribution)
- infoUse: "When anxiety or overwhelm pulls you out of the moment."
- infoExample: "Panic rising in a crowded room — name 5 things you see, 4 you hear, 3 you can touch, 2 you smell, 1 you taste, and you're back in your body."
- flow: step through the five senses (5 see → 4 hear → 3 touch → 2 smell → 1 taste), tap or type each; gentle completion. Optional "used today" log.

**Nervous-System Reset** (type: statepractice) · icon 🌊 · purpose "Find your state, then settle your body."
- credit: "Polyvagal theory — Dr. Stephen Porges; practice via Deb Dana; physiological sigh via Dr. Andrew Huberman (Stanford)."
- infoUse: "When you feel wired and panicky, or flat and shut down, and want to bring your body back toward calm."
- infoExample: "Before a hard conversation your chest is tight and your mind races. You name it as fight-or-flight, then take three physiological sighs before you walk in."
- flow: pick your state — Safe & connected (ventral) / Fight-or-flight (sympathetic) / Shut down (dorsal), each in plain language with a "no wrong state" note → physiological-sigh breathing animation (two short nasal inhales + one long mouth exhale, ~3 rounds, animated circle) → optional state re-check. Optional "used today" log.

### Self-knowledge tools
**Attachment** (type: attachment) · icon 💞 · purpose "Understand your patterns in relationships."
- credit: "Based on Levine & Heller, Attached (2010); attachment theory of Bowlby & Ainsworth."
- infoUse: "When you feel a spike of worry, clinginess, or the urge to pull away in a relationship."
- infoExample: "Someone doesn't reply for hours; your chest tightens and you start drafting a follow-up. This helps you catch that as your attachment system activating and choose your next move on purpose."
- flow: FIRST USE — identify your style (Secure / Anxious / Avoidant, self-select with one-line descriptions, or a short 6-question check), framed as a pattern not a verdict, stored in fulfillx.attachmentStyle (editable later). THEREAFTER — "system activated" reflection (diary engine, tuned to the saved style): 1) "What just happened?" 2) "What are you feeling or fearing?" 3) choice: "Is this the situation, or my pattern?" [Situation / My pattern] 4) "What would secure do here?" Saved to history.

**Observer** (type: ladder) · icon 👁️ · purpose "Step back from a thought that's got you."
- credit: "ACT cognitive defusion — Dr. Steven Hayes; popularized by Dr. Russ Harris."
- infoUse: "When a harsh, sticky thought has you hooked and you're treating it as flat fact."
- infoExample: "'I always mess things up' is on loop. Instead of arguing with it, you step back and watch it: 'I'm having the thought that I always mess things up.' The grip loosens."
- flow: enter the hooking thought → unhooking ladder showing three rungs: the raw thought (fused) → "I'm having the thought that …" → "I notice I'm having the thought that …", each visibly more distanced → close on "You are the sky. Thoughts are just the weather passing through." → save dated entry. History = a log of thoughts unhooked from (recurring hooks become visible).
- note: distinct from Thought Record — Observer does NOT argue with the thought, only unhooks.

**Values** (type: bullseye) · icon 🧭 · purpose "Find your compass — what you want to stand for."
- credit: "ACT values work — Dr. Steven Hayes; Bull's Eye by Tobias Lundgren; via Dr. Russ Harris."
- infoUse: "When you feel directionless or pulled by others' expectations and want to reconnect with what matters."
- infoExample: "'Get married' is a goal — you tick it off. 'Be loving and present' is a value — a direction you never finish walking. Values are the compass; goals are the stops."
- flow: name your values per domain (Work/Education, Leisure, Relationships, Personal Growth/Health) stored in fulfillx.values (editable living list) → Bull's Eye: a four-quadrant dartboard where you mark how close to center you're living in each domain (center = living fully by them) → save a dated snapshot to history. History shows the living values list + past Bull's Eye snapshots so the user can see their aim improve.

## PHASES

### PHASE 1 — Toolbox shell: registry, cards, info popups
Define the in-code tool registry (all tools above with name/icon/purpose/credit/infoUse/
infoExample/type). Replace the Toolbox tab placeholder with a scrollable list of tool cards:
icon, name, purpose, credit line (small, italic, muted), and an "i" info button top-right.
The "i" opens a popup with "When to use it" + "Example." Tapping a card routes to that tool's
screen (flows stubbed until their phase). Optional: light grouping (e.g., In the moment /
Reflect & journal / Know yourself).
Acceptance: every tool shows a card with its EXACT credit; every "i" shows the right use case
+ example; tapping a card opens a (stub) tool screen; both themes render correctly.

### PHASE 2 — Guided-diary engine + per-tool history
Build the `diary` flow renderer: from a tool's `steps` (text fields, or choice pills where
specified), render a guided flow; on save write `{date, ts, data}` to
`fulfillx.toolEntries[toolId]`. Build a per-tool History view (recent-first list; tap to
reopen an entry read-only), reachable from the tool screen. Validate with ONE diary tool
(the 5 R's), including its footer "every refusal is a win" note.
Acceptance: the 5 R's runs all five steps, saves a dated entry, lists it in history, reopens
read-only; data persists; both themes fine.

### PHASE 3 — Remaining diary tools (content)
Using the Phase 2 engine, implement the other diary tools from the catalog: Shadow Work,
Dichotomy of Control, Elephant & Rider, Thought Record, NVC, Shame Resilience. Each = credit
+ info popup + paraphrased steps. NVC additionally assembles its four answers into a draft
message at the end. (If too large for one response, split across two commits.)
Acceptance: each diary tool opens with the correct credit + info, runs its steps, and saves
to its own history; NVC produces a draft message.

### PHASE 4 — Mind Dump + 5-4-3-2-1 + usage logging
Mind Dump (braindump): duration pick → timed free-write → review/cross-off → capture next
actions → save dated entry. 5-4-3-2-1 (grounding): step through the five senses to a gentle
finish. Add the optional "used today" logging to `fulfillx.toolUsage` for in-the-moment tools.
Acceptance: Mind Dump timer + review + actions save; 5-4-3-2-1 completes; usage logs record.

### PHASE 5 — Nervous-System Reset + Attachment
Nervous-System Reset (statepractice): state picker → physiological-sigh breathing animation
(two nasal inhales + long mouth exhale, ~3 rounds) → optional re-check; usage log. Attachment:
first-run style identification stored in `fulfillx.attachmentStyle` (editable), then the
style-tuned "system activated" reflection saving to history.
Acceptance: breathing animation runs the correct rhythm; state recorded; attachment style
sets once and is editable; the reflection saves dated entries.

### PHASE 6 — Observer + Values
Observer (ladder): enter the thought → three-rung unhooking ladder → sky/weather close →
save dated entry; history of unhooked thoughts. Values (bullseye): capture values per domain
into `fulfillx.values` → Bull's Eye alignment → save dated snapshot; history shows the living
values list + past snapshots.
Acceptance: Observer ladder + history work; Values stores values, captures a Bull's Eye
snapshot, and shows the compass + dated snapshots.

### PHASE 7 — Polish + Insights + final pass
Add a small "Toolbox" readout to Insights (which tools used, how often / recently, from
toolEntries + toolUsage). Add empty states for every tool history. Verify all new screens in
both Slate and Graphite; confirm no localStorage bloat. Provide a final checklist over every
acceptance criterion.
