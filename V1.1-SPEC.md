# FulFillX — V1.1 Specification (Phased Build)

The app is a single self-contained HTML file, `FulFillX.html` (HTML + CSS + JS inline,
no build step, no dependencies except Google Fonts). It MUST stay a single file so it
runs by double-clicking in a browser. All data persists in `localStorage`. No backend.

## HOW TO BUILD THIS (read first)
Execute the six phases below **in order, one at a time**. For each phase:
1. Make ONLY that phase's changes, using targeted/incremental edits. Do NOT rewrite the
   whole file in one response — that overflows the output limit.
2. After the phase compiles and meets its acceptance criteria, output a short summary of
   what changed and how to verify it, then continue to the next phase.
3. Treat each phase as its own unit of work so no single response is oversized.
Keep all existing behavior working unless a phase explicitly changes it, and never break
or discard existing localStorage data.

## DESIGN TOKENS (shared reference for all phases)

Use CSS custom properties on a root element; switch themes by toggling a class
(`.theme-slate` / `.theme-graphite`). Every color must come from a variable.

## PHASE 1 — Typography
Apply the Baloo 2 / Fredoka rules above across the whole app; remove Caveat. Change
nothing else.
Acceptance: headings render in Baloo 2, all subtext in Fredoka, no serif fallback, layout
otherwise unchanged.

## PHASE 2 — Theme system
Set up Slate/Graphite as CSS variables on the root, switched by a class. Default to
`prefers-color-scheme`; persist a manual choice in `localStorage` key `fulfillx.theme`
("light" | "dark" | "system"). Replace the old time-of-day gradient background. Route all
existing colors through the variables so both themes work everywhere. No layout/journal
changes yet (toggle UI comes in Phase 3).
Acceptance: app loads in the correct theme per OS setting; both themes render correctly
everywhere; old gradient gone.

## PHASE 3 — Home layout (Option B) + Settings screen
Home, persistent and NON-scrolling at normal phone height:
- Top bar: `FulFillX` wordmark (Baloo 2, uppercase, letter-spacing ~1.3px, "X" in an
  accent rounded box) left; settings gear button right.
- Greeting (Baloo 2 ~36px) + date (Fredoka); quote (Baloo 2 ~18px) + author (Fredoka).
- Flexible spacer pushes the journal area to the bottom.
- Morning anchor card (🌅, "Morning", "Plan your day & set intentions"); Evening anchor
  card (🌙, "Evening", "Reflect on your day"); a small CENTERED dashed pill beneath them
  labeled "+ Quick daytime check-in" (clearly the optional element).
- Bottom nav unchanged: Home / Toolbox / Habits / Insights. The gear is NOT a 5th nav item.
Settings screen (opened by the gear): Light/Dark/System theme control wired to Phase 2; a
"Customize journals" placeholder section (filled in Phase 6); a clear way back to Home.
Acceptance: wordmark left + gear right; gear opens Settings; toggle switches live and
persists; Option B layout present; home does not scroll.

## PHASE 4 — Journal restructure (with Main Goal loop)
Keep save/load/persistence, completion badges, toast, and Insights working.
- MORNING (anchor), in order: Sleep quality 1–5 buttons + "Hours slept" number; Gratitude
  text ("What's one thing you're grateful for today?"); Affirmation text ("What is one
  affirmation you can give yourself this morning?"); Main Goal of the Day, single text
  input ("What do you want to move toward today?"); Morning Habits checklist
  (Meditation, Read 10 min, Exercise).
- EVENING (anchor), in order: Goal review (CLOSES THE LOOP) — show today's morning Main
  Goal read-only and ask "Did you work toward it?" with Yes / Partly / No + optional note;
  if no morning goal, show a gentle placeholder. Reflection text ("What was a win today?
  What would you do differently?"); Evening Habits checklist (Reading, Book Club prep,
  Meditation); Sleep Intention text ("What will help you sleep well tonight?").
- DAYTIME (flex), minimal/fixed: quick mood emoji scale (😔 😐 😊 😄) + optional one-line note.
Acceptance: all three journals open/save/reload with data intact; morning Main Goal
appears in the evening goal-review; badges, toast, Insights still work.

## PHASE 5 — Widget engine
Introduce the config model and render journals from it. Seed on first run with the Phase 4
defaults so journals look identical until edited.
`localStorage` key `fulfillx.config`:
```
{
  "morning": [
    { "id": "sleep",       "type": "sleep",     "title": "How did you sleep?",   "config": { "scaleMax": 5, "numberLabel": "Hours slept" } },
    { "id": "gratitude",   "type": "text",      "title": "Gratitude",            "config": { "prompt": "What's one thing you're grateful for today?" } },
    { "id": "affirmation", "type": "text",      "title": "Affirmation",          "config": { "prompt": "What is one affirmation you can give yourself this morning?" } },
    { "id": "maingoal",    "type": "maingoal",  "title": "Main Goal of the Day", "config": { "prompt": "What do you want to move toward today?" } },
    { "id": "habits-am",   "type": "habits",    "title": "Morning Habits",       "config": { "items": ["Meditation","Read 10 min","Exercise"] } }
  ],
  "evening": [
    { "id": "goalreview",  "type": "goalreview","title": "Today's Main Goal",     "config": {} },
    { "id": "reflection",  "type": "text",      "title": "Reflection",           "config": { "prompt": "What was a win today? What would you do differently?" } },
    { "id": "habits-pm",   "type": "habits",    "title": "Evening Habits",       "config": { "items": ["Reading","Book Club prep","Meditation"] } },
    { "id": "sleepintent", "type": "text",      "title": "Sleep Intention",      "config": { "prompt": "What will help you sleep well tonight?" } }
  ]
}
```
Widget types: `text` (prompt+textarea), `scale` (1..N buttons; config.scaleMax),
`number` (config.label), `sleep` (1–5 scale + hours number), `emoji` (config.emojis,
default 😔😐😊😄), `habits` (config.items[]), `maingoal` (single text the evening reads
back), `goalreview` (read-only today's maingoal + Yes/Partly/No + note).
Entries (`fulfillx.entries`) keyed by date → journal → widget id → value, so reordering
never loses data. Morning and Evening must now BUILD their form by iterating their config
array and rendering each widget by type; save reads values back by widget id.
Acceptance: with the seeded config the journals look exactly like Phase 4; entries
save/reload; the morning→evening loop still works through rendered widgets.

## PHASE 6 — Customization editor
In Settings "Customize journals", for Morning and Evening: list current widgets in order;
reorder with up/down buttons; remove a widget; add a widget (pick a library type, set its
title/prompt, and items for habits); edit a widget's title/prompt/items; a per-journal
"Reset to defaults". All edits write to `fulfillx.config` and reflect immediately.
Acceptance: add/remove/reorder/edit all work and persist across reloads; entries survive
reordering (keyed by id); reset-to-defaults works; the Main Goal loop still works.
